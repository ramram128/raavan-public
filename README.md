# Morrow & Pine

## Project structure

- `frontend/`: React application, Vite configuration, dependencies, and build output.
- `backend/`: Reserved for the backend API and server code. No backend currently exists.

## Run the frontend

From the project root:

```sh
npm --prefix frontend install
npm run dev
```

Build for production with `npm run build`, or preview the build with `npm run preview`.

You can also run `npm run dev`, `npm run build`, and `npm run preview` directly inside `frontend/`.
